# model-router wiki

A Claude Code plugin that picks a model for each subagent and shows what it cost. This fork routes mechanical work to Haiku, caps effort by tier and keeps a feedback loop (code2-workspace issue 162).

Read in this order:

1. [README](../README.md): how routing works, the tier and effort table, settings and limits.
2. [CHANGELOG](../CHANGELOG.md): what changed and when.

5. [System model](../docs/planning/SYSTEM.md): what the plugin stores, changes and shows.
6. [Glossary](../docs/planning/DOMAIN.md): each concept, where the code implements it.
