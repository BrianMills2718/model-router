Q4: Can a plugin set the main model? resolved

Can any plugin mechanism set the main conversation's model or effort? The report read only the first 100k of 288k characters of the hooks reference and says to grep the tail for setModel and CLAUDE_ENV_FILE before relying on 'impossible'.

Blocks: whether README 'Limits' may state that the main-model lever is manual

Evidence: Read 2026-11-06 the full hooks page (code.claude.com/docs/en/hooks) and model-config page. PreModelSwitch 'accepts allow, deny and ask; it doesn't accept defer, updatedInput or additionalContext', so it cannot substitute a model. CLAUDE_ENV_FILE (SessionStart) persists variables 'for the shell commands Claude runs later', not Claude Code's own model; $ANTHROPIC_MODEL 'doesn't change when you switch models with /model'. setModel() belongs to the Agent SDK, for apps. No plugin mechanism sets the main model.

How it was settled: Prior art: grep the unread tail of the hooks and model-config pages for setModel, model in hook output and CLAUDE_ENV_FILE.

Q10: Are the 12% and 3% thresholds calibrated? resolved

Are the 12% raise and 3% lower thresholds calibrated for samples of 10 and 30 runs?

Blocks: accepting any weekly decision

Evidence: Computed 2026-11-06 (Wilson score interval, z=1.96): 0/30 -> 0.0-11.4%, 1/30 -> 0.6-16.7%, 2/10 -> 5.7-51.0%, 3/10 -> 10.8-60.3%. Conclusion: the thresholds are screens for what to read, not proof. A proposal is never accepted on the rate alone; the review already carries 'read these traces' and a clean week is called weak evidence (docs/planning/evidence/router-weekly-review-sample.md:3). Consequence kept in the plan: accept a lowering only after a session reads sampled traces, and let evidence accumulate across weeks.

How it was settled: Argument with a computed interval (Wilson 95%): 2 bad of 10 runs (20%) has a true-rate interval of 5.7% to 51%; 3 of 10 is 10.8% to 60%; 0 bad of 30 runs has 0% to 11.4%; 1 of 30 is 0.6% to 16.7%. So one week cannot separate a 3% rule from a 12% one, and 0 of 30 cannot rule out a rate near the 12% raise line.
